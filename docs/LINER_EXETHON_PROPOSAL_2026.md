## 1. 해결하고자 하는 실무 현장의 고질적 문제 (현장 암묵지의 부재)

생성형 AI(LLM)의 발전으로 단순 텍스트 번역은 쉬워졌으나, **실제 영상 자막 및 청각장애인을 위한 SDH(Subtitles for the Deaf and Hard of Hearing) 자막 제작 현장**에서는 여전히 사람이 수작업으로 전수 재작업을 거쳐야 합니다.

범용 LLM이 영상 자막 제작에서 실패하는 3대 고질적 병목:
1. **물리적 시공간 제약식 위반**: 영상 자막은 화면 가림 방지를 위해 **'1줄 최대 16자, 최대 2줄'**, 시청자의 안구 이동 속도를 위해 **'초당 4~5자(Reading Speed)'**라는 엄격한 물리 법칙을 지켜야 합니다. 일반 LLM은 이를 무시하고 문장을 길게 늘여 써 자막이 화면을 덮어버립니다.
2. **타임코드(TC) 인점·아웃점 파괴**: 대사가 끝났는데도 자막이 남아있거나 화면 전환(Shot Change) 컷을 넘어가 시청자에게 극심한 시각적 피로를 유발합니다.
3. **고유명사 및 문화적 뉘앙스 할루시네이션**: 최신 신조어, 인명, 역사적 배경 지식을 지어내거나 번역투로 직역합니다.

현업 10년 차 이상의 영상번역가는 **"어떤 조사를 생략해야 16자 안에 의미를 압축할 수 있는지", "화면 전환 0.04초 전에 자막을 닫아야 하는지"**를 오랜 감각(암묵지, Tacit Knowledge)으로 처리합니다. 본 프로젝트는 이 숙련된 번역가의 두뇌 속 검수 규범을 AI 에이전트로 명문화하고 시스템화합니다.

## 2. 제안하는 AI 에이전트 솔루션 구조

플리토(Flitto)의 EMNLP 2026 연구 성과인 **Judge & Refine(판정과 교정) 루프**와 **Liner Search API**를 결합한 **4단계 자가교정 멀티모달 자막 에이전트**를 구축합니다.

```
[영상/오디오 입력] 
       ↓ (WhisperX 음소 단위 정렬)
[1단계: 초안 생성 에이전트 (Drafting Agent)]
       ↓
[2단계: 4차원 판정 에이전트 (Judge Agent)]
  - 차원 1: 글자 수 검수 (1줄 16자 / 2줄 제한)
  - 차원 2: 초당 노출 속도 검수 (CPS ≤ 4.5)
  - 차원 3: 타임코드 스냅 검수 (컷 전환 넘침 방지)
  - 차원 4: 고유명사·맥락 팩트 검수 (Liner Search API 연동)
       ↓
       ├─ [규범 100% 통과 시] ──→ [최종 납품용 SRT/VTT 파일 출력]
       │
       └─ [규범 위반 발생 시]
              ↓
[3단계: 실시간 지식 보강 (Liner Search API & MCP)]
  - 라이너 서치 API를 호출해 인명, 브랜드, 고유명사, 최신 시사 팩트 실시간 교차 검증
              ↓
[4단계: 국소 자가교정 에이전트 (Refine Agent)]
  - 타임코드 원본은 0.01초도 건드리지 않고, 위반된 텍스트만 국소적으로 문맥을 살려 16자 이내로 압축 재작성
              ↓
       [2단계 판정으로 회귀 (수렴할 때까지 최대 3회 루프)]
```

## 3. 라이너 API (Liner API & MCP) 접목 방안

- **Liner Search API의 결정적 역할**:
  자막 번역 중 가장 위험한 것은 고유명사 왜곡입니다. 에이전트가 자막을 검수할 때 고유명사나 전문용어가 등장하면, **라이너 서치 API를 통해 웹상의 공신력 있는 최신 백과사전 및 보도자료를 실시간 쿼리하여 공식 표기법을 확정**합니다.
- **Liner Model API & MCP 통합**:
  라이너 플랫폼 크레딧을 기반으로 고성능 추론 모델과 검색 도구를 결합해, 외부 브라우징 없이도 에이전트 내부에서 완전한 자가교정 폐루프(Closed Loop)를 달성합니다.

## 4. 기대 효과 및 파급력

1. **자막 제작 공수 70% 단축**: 60분 영상 기준 평균 6~8시간 걸리던 번역·싱크·검수 작업을 초벌 3분 + 에이전트 검수 2분으로 단축, 번역가는 최종 감수에만 집중 가능.
2. **배리어프리(SDH) 자막 품질의 상향 평준화**: 음향 효과([문이 쾅 닫힌다], [비장한 음악]) 표기 규칙과 엄격한 속도 제약을 완벽 준수하여 청각장애인의 미디어 접근권 혁신.
3. **만 40세 이상 실무자의 현장 노하우가 자산화되는 모범 사례**: 코딩 비전공자 실무자라도 클로드 코드 등 최신 AI 코딩 도구와 라이너 API를 오케스트레이션하여 고난도 도메인 문제를 해결할 수 있음을 입증.
