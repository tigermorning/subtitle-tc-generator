# MVP — 지금 실제로 되는 것

[`PRD.md`](PRD.md)의 목표에 대해 **지금 이 저장소가 실제로 하는 일**만 적는다.
계획이나 바람이 아니라 동작 확인된 것 — 근거는 README·git 커밋·`tests/run_tests.py`
통과 여부다. 새로 지어내지 않는다.

## 되는 것

### 규정 검사 (CLI, `python -m checker`)

- 넷플릭스(한국어·영어, SDH·번역, `official: true`, Korean TTSG 2025-07-07 개정
  기준), 디즈니+·쿠팡플레이(한국어, SDH·번역, `official: false` — 공식 문건
  미확보라 작업자 실무 자료 기준)
- 위반마다 조항 번호 인용, `[자동]`/`[확인]` 구분, 미구현 검사는 숨기지 않고
  `미구현 검사`로 별도 표기
- `--fix`(자동 교정, 원본 불변·새 파일로 출력), `--fix-timing`, `--korean`(한국어
  교정기 레인 연동), `--terms`(용어 조사), `--characters`(캐릭터 분석 문서),
  `--backtranslate`(역번역 검증)

### 자막 초벌 생성 (`--generate`)

- 영상 → ffmpeg 내장 whisper 전사 → (스크립트 있으면 대조) → 의미 단위 재분할
  → Silero VAD(없으면 음량) 기반 스포팅 제안 → 규정 자동 교정 → 검사까지 한 번에
- 화자명은 스크립트 없이는 못 넣는다(whisper가 화자 분리를 못 함 — 정직하게 표시)
- 번역은 `--translate`로 로컬 Ollama 다차 검수(1차 정확도 → 2차 용어·맥락 →
  3차 윤문·글자 수), 드리프트 가드·역번역 검증 포함

### 정답 대조 (`--against`)

- 우리 결과와 정답 자막을 구조적으로 대조(짝지음/빠뜨림/군더더기, 인점·아웃점
  편향의 가운데값·흩어짐·최악)
- **2026-08-26 첫 실전 사용**으로 `checker/timing.py`의 실제 구조적 버그(스포팅이
  근처 말소리 구간 전체 끝까지 과도하게 늘어나는 문제)를 발견·수정함 —
  `.claude/skills/정답지-대조-진단/`이 이 절차를 코드화한다

### 코퍼스 학습 (`rules/learned/`)

- `tools/corpus_build.py`로 시판·방영 영상의 정답 자막 트랙에서 통계(글자 수·CPS·
  듀레이션·간격 분포)를 추출
- 2026-08-26 기준 10개 발주처 버킷(netflix·disney·coupang·amazon·appletv·hbo·
  viki·viu·bluray·unknown) 아래 학습값 존재 — `platform: unknown`은 발주처를
  특정 못 한 자료(예: 다발매 PVOD 영화)를 위한 임시 버킷
- **공식 규정 파일(`rules/<platform>/`)을 절대 건드리지 않는다** — 학습값은
  `rules/learned/`에만 쌓이고, 규정으로 승격하려면 사람 확인을 거친다(CLAUDE.md
  규칙 11)
- `.claude/skills/정답지-학습/`이 이 전체 절차(무결성 확인→추출→기록→백업→정리)를
  코드화한다

### GUI 앱 + SubtitleEdit 연동

- Windows용 독립 실행 파일(`dist/자막생성기/자막생성기.exe`, 파이썬 불필요).
  영상·파형·자막 표를 한 화면에 두고 위 단계들을 실행
- SubtitleEdit 4.x 플러그인(`plugin/se4/`, 동작 확인·설치됨) — SE 안에서 우리
  검사·교정을 부를 수 있다

## 범위 밖 (의도적으로 안 만든 것)

- **자막 편집기 UI** — SubtitleEdit을 대체하지 않는다(PRD 참고, 2026-08-12 결정)
- **클라우드 번역·전사** — 로컬 전용이 설계 원칙이다(PRD, CLAUDE.md 규칙 6)
- **노래·박수·비대사 발성의 자동 분류** — 2026-08-26, 세 작품(예능A·영화D·
  영화F, 한국어 예능·영어 실사영화·영어 애니메이션)에서 공통
  확인됨: whisper가 가사·효과음·군중 반응을 대사처럼 전사해 스포팅이 길게
  늘어짐. 오디오만으로 "이게 대사인지 아닌지" 판별하는 기능은 아직 없다 —
  `checker/timing.py`의 스포팅 확장 상한(`max_shift_ms`)이 가장 심한 과확장만
  막을 뿐, 근본 원인은 남아 있다. `BACKLOG.md`에 다음 작업으로 남김
