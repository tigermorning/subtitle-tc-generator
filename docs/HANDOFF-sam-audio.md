# 인계: SAM Audio로 대사 분리 → 인·아웃 찾기 돕기 (2026-11-13, 아이펠 PC)

## 목표
SAM Audio(Meta)로 대사만 분리한 트랙을 만들어, 파형으로 인점·아웃점을 찍을 때 **안내용**으로 쓸 수 있는지 확인한다.
분리 트랙으로 TC를 바로 뽑는 것이 아니다. 최종 경계는 원본 파형에서 정한다(생성 모델이라 말끝·무음이 바뀔 수 있음).

## 확인한 사실 (출처)
- 코드 `facebookresearch/sam-audio` 커밋 `bb4c699`(2026-05-26)를 직접 읽음.
  - 출력 48kHz(`sam_audio/model/config.py:22`), 코덱 배율 12·10·8·2 = 1920샘플 → 25칸/초, **40ms 단위**.
  - 글만 넣으면 `predict_spans`(`model.py:231`)가 `pe-a-frame-large`로 구간을 자동 추정해 함께 넣는다.
  - 구간(span) 토큰: `+`(목표 소리 있음), `-`, `<null>`, `<pad>`(`processor.py:80`).
- 논문 arXiv 2512.18099은 일꾼이 읽음(대부분 요약을 거침): 글+구간을 같이 넣으면 글만보다 낫다고 함. 한국어 평가 없음. 시간 정확도는 SpanIoU뿐.
- 대본 글자를 넣는 기능은 없음. 글 지시는 "speech" 같은 **소리 설명**이다. 스크립트는 시각을 맞춰 **구간(+)** 으로 바꿔 넣을 때만 쓸모가 있다.
- 아이펠 PC에는 `nvidia-smi`가 없어 로컬 실행은 못 함 → 웹 Playground 사용.
