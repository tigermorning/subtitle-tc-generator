## 왜

`_strip_trailing_notes`의 주석이 이미 적고 있었습니다.

> 번역만 내고 설명은 붙이지 말라는 지시를 프롬프트에 이미 넣었지만, **모델이 가끔 어긴다.**

프롬프트는 부탁이라 확률적으로만 지켜집니다. 그래서 사후 정제가 세 겹 쌓였습니다.

| 함수 | 무엇을 벗기나 | 실측 |
|---|---|---|
| `_strip_markdown_wrap` | 번역문 전체를 `**...**`로 감쌈 | 영어 127곳, 한국어 76곳 |
| `_strip_trailing_notes` | 끝에 `**Notes:**` 자기 설명 | 예능A 15회 |
| `_strip_self_revision` | `원래 → 고침` 자기 수정 | 13곳 |

## 무엇을

Ollama HTTP의 `format`에 JSON 스키마(`_TRANSLATION_SCHEMA`)를 실어 **서버가 형식을 강제**하게 했습니다. 스키마에 없는 꼬리 설명이나 한 칸에 든 두 값은 나올 수 없고, "모델이 어떻게 답하든 번호를 붙잡는다"던 `_parse_numbered`의 추측도 그 경로에서는 필요 없어집니다.

`ollama run`(cli)에는 그 자리가 없습니다. WSL에서 Windows 쪽 Ollama를 부를 때 유일한 길이라 없앨 수 없어, `supports_schema`로 갈라 **강제가 걸리는 경로만** 새 규격을 씁니다 — 강제가 안 걸리는데 JSON을 요구하면 형식은 안 지켜지면서 번호마저 잃습니다.

## 리뷰 때 봐 주셨으면 하는 곳

**1. 두 인자 `ask` 호환** — 시험용 가짜 번역기 10개가 전부 `ask(self, system, prompt)`입니다. 항상 3인자로 부르면 다 깨집니다. 그래서 스키마를 안 쓸 때는 인자를 빼고 부릅니다.

```python
reply = (translator.ask(system, prompt, _TRANSLATION_SCHEMA) if use_schema
         else translator.ask(system, prompt))
```

**2. `None`과 `{}`를 구분합니다** — `_parse_schema_reply`에서 "JSON이 아니다"(`None`)와 "JSON은 맞는데 쓸 항목이 없다"(`{}`)는 다른 뜻입니다. 뭉개면 cli 경로 번역이 통째로 빕니다.

**3. 정제 함수 셋을 그대로 남겼습니다** — 스키마는 **구조**만 보장합니다. `text` 값 *안에* 강조 표시가 들어오거나 한국어가 섞이는 것(A.20, 영화B 일본어 1434개 중 93개)은 여전히 사후 처리 대상입니다.

## 범위

`translate_events`만 손댔습니다. `revise.py`·`backtranslate.py`·`terms.py`도 같은 `_parse_numbered`를 쓰지만 건드리지 않았습니다 — 규칙 12(가닥을 동시에 벌이지 않는다). 배관은 공유되므로 나중에 스키마를 넘기기만 하면 됩니다.

### #3 기본값이 결정인 척하지 않게 한다 — 결정표

## 왜

`-p`를 안 주면 argparse가 조용히 `netflix`를, `-k`를 안 주면 `translation`을 채웠다. 화면에 찍히는 `프로파일: netflix ko translation` 한 줄은 **사람이 고른 것과 기계가 채운 것을 구분하지 못했다** — CLAUDE.md 규칙 1의 ⓪(발주처 확인이 모든 작업에 앞선다)가 도구 안에서 사라지는 자리였다.

`--generate`에서는 더 나빴다. `detect.mismatch_warning`이 유일한 방어막인데, 생성 경로에서는 넷플릭스 프로파일로 자동 교정해 쓴 **자기 출력물**을 되읽으므로 경고가 원리적으로 안 뜬다(순환).

## 무엇을

**값은 바꾸지 않는다** — 예전 명령이 같은 결과로 돌아야 한다. `decisions.resolve()`가 똑같이 채우되 출처(`user`/`default`/`file`/`none`)를 남긴다. 규칙 11이 승격한 학습값에도 `origin: learned`를 지우지 않는 것과 같은 이유다.

| 자리 | 전 | 후 |

| `-p` 미지정 | 조용히 netflix | netflix로 채우되 경고 + 결정표 `<- 확인 필요` |
| `-k` 미지정 | 조용히 translation | 같음 (SDH 파일이면 효과음 규칙이 통째로 빠진다는 안내 포함) |
| 장르 미지정 | 리포트에 아무 줄 없음 | `장르: 미지정 (장르 관행을 얹지 않았습니다)` — 규칙 17 사고 ③ |
