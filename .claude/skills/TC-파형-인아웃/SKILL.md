# TC 작업: 사람 음성 파형으로 인점·아웃점 잡기

2026-11-12 사용자와 한 세션에서 정한 것을 모은 표준 절차다. 이 절차 밖의 방식(하드섭
화면 글자, OCR, whisper 전사, 뜻 단위 분할)으로 TC를 잡지 않는다.

## 1. 원칙 (사용자 지정)

- **TC 작업 = 사람 음성이 나오는 자리만 잡는 일.** 내용·의미 파악은 필요 없다.
- **영상 번역 자막과 SDH 모두 사람 음성만**으로 작업한다. 효과음·음악이 TC에 들어가면 안 된다(사용자 2026-11-12 정정).
- **항상 SE가 파형을 받은 뒤**, 그 SE 파형으로 인점·아웃점을 잡는다(사용자가 SE에서 보는 파형과 같은 자료).
- 대본은 **텍스트를 넣고 글자 수로 나누는 데만** 쓴다. 뜻으로 끊는 자리를 정하지 않는다.
- 결과를 뜻 단위로 끊긴 기존 자막(방송 자막, 영어 자막 트랙, 옛 수정본)과 «끊는 자리가 다르다»로
  견주지 않는다. 확인은 음성 파형과 직접 대조한다.

## 2. 규정

| 항목 | 값 | 출처 |
|---|---|---|
| 인점 | 음성 시작 전 **모눈 한 칸(0.1초 이내)** | 사용자 이미지·지적 |
| 아웃점 | 음성 끝 후 **모눈 2.5~3칸(0.25~0.3초)** | 사용자 지적(처음 이미지는 0.2~0.3초) |
| 겹칠 때 | 다음 말소리의 **인점 우선**(앞 자막 아웃점을 자름) | 사용자 이미지 |
| 최소 표시 | 아웃점 규칙보다 **Minimum Duration 우선**(1.0초, 다음 인점은 넘지 않음) | 사용자 이미지, 값 1.0초는 CLAUDE.md |
| 최대 표시 | **7초를 넘으면 대본 줄 경계에서 나눔** | 사용자, 넷플릭스 규정 |
| 자막 사이 간격 | **발주처마다 다름: 0 또는 2프레임** — 작업 시작 때 묻는다 | 사용자 |
| 쉼에서 나누기 | 기본 **0.2초** 이상 쉼. 대본이 있어 글자 수가 넘치면 **0.08초** 쉼에서도 | 사용자 |
| 한 자막 최대 글자 | 영어 42×2=84, 한국어 16×2=32(`rules/private/netflix/*`) | 규정 파일 |
| 장면전환 | **SDH만** 앞뒤 최소 0.5초(그 안이면 장면전환에 붙임). **영상 번역 자막은 쓰지 않음** | 사용자 |

장면전환 세부(내가 정함, 사용자 확인 전): 인점을 장면전환에 붙이면 음성 시작을 자르게 될 때는
인점을 장면전환 0.5초 앞으로 당긴다. 다음 인점이 장면전환이면 앞 아웃점은 «장면전환 − 간격» 허용.

## 3. 작업을 시작할 때 먼저 묻는 것

1. 영상 파일과 구간(예: 02:00~05:00, 3분)
2. 종류: **SDH**인가 **영상 번역 자막**인가
3. 발주처 요청 **자막 사이 간격**: 0프레임인가 2프레임인가
4. 대본이 있는가(있으면 시각 있는 참고 자막도 — 보통 영상 안 자막 트랙)

## 4. 한 번에 돌리기

```bash
# 대본이 있으면 참고 자막을 먼저 뽑는다
ffmpeg -i <영상> -map 0:s:0 ref_eng.srt
python tools/waveform_tc/run_tc.py <영상> <시작초> <길이초> <결과폴더> <fps> <간격프레임> <sdh|translation> [<대본.txt> <참고자막.srt> <최대글자>]
# 예: py tools/waveform_tc/run_tc.py Toy.Story.5...mkv 300 180 "파형TC_05-08분" 24 0 translation transcript.txt ref_eng.srt 84
```

- fps: `ffprobe -select_streams v:0 -show_entries stream=r_frame_rate`(29.97은 `30000/1001`).
- 3분 음성 분리에 CPU로 약 3분 — 백그라운드로 돌린다. 분리 결과를 다시 쓰려면 `REUSE=1`.
- 끝나면 SE4가 결과(`clip_음성만.srt`)로 다시 열린다. 사용자에게 알린다.

순서(스크립트 안):
1. 구간 원음 추출. **5.1·7.1이면 센터 채널(FC)만**(대사가 주로 있는 채널).
2. 음성 분리 `separate_onnx.py`(MDX-Net `Kim_Vocal_2.onnx`, onnxruntime CPU) → `voice_sep.wav`.
3. 사람 말소리만 `vad_mask.py`(저장소 `models/silero_vad.onnx`, 말소리 아닌 자리를 0, 앞뒤 여유 0.3초) → `voice_only.wav`.
4. `clip.mp4`(원음) + `clip_음성만.mp4`(소리를 3번 결과로) 만들기.
5. SE4를 닫고 다시 열어 **SE가 파형을 받을 때까지 기다림** → SE4 `Waveforms/*.wav`(초당 150점)를 `se_waveform.wav`로.
   소리가 전과 같으면 SE가 저장된 파형을 재사용해 새 파일이 안 생긴다 → 30초 뒤 길이가 맞는 가장 최근 파형을 쓴다.
6. SDH면 장면전환 검출(`checker.media.detect_shot_changes`, 민감도 0.2) → `shots.json`.
7. `wave_tc.py` → 음성 조각과 인점·아웃점(`wave_only.srt`, `.json`). 5절 판정.
8. 대본이 있으면 `fill_script.py` → 텍스트 넣기·나누기·대본 없는 조각 지우기(6절).
9. 자리를 못 찾은 대본 줄이 있으면 **2차 패스**(6절) — 3·4·5·7·8을 한 번 더.
10. `clip_음성만.srt`, `clip.srt`(구간 기준), `wave_tc_원본시각.srt`(원본 시각)를 쓰고 SE4를 결과로 다시 연다.

대본이 없으면 자막 칸에 텍스트 대신 `#번호 음성 시작–끝(초)`이 들어간다.

## 5. 파형 판정 (`wave_tc.py`, 내가 정한 값 — 바꾸면 여기 고친다)

1. **말소리 조각 찾기**: SE 파형 꼭짓값(dB)이 문턱 = max(하위 20% + 20dB, 상위 1% − 35dB)를 넘는 곳.
   영상마다 정한다(고정 −38dB는 조용한 영화에서 작은 소리를 놓쳤다). 시작·끝을 넓히지 않는다.
2. **쉼으로 나누기**: 0.2초 이상 조용하면 끊는다. 0.12초보다 짧은 소리는 버린다.
3. **소음 조각 거르기**(`WAVE_TC_VAD_SRC` = `voice_sep.wav`): 조각마다 VAD 확률 평균이 0.5 이상이면 남긴다.
   평균이 낮으면 통째로 버리지 않고 **확률 0.5 이상인 부분만** 남긴다(한 조각에 소음과 말소리가 함께 있을 수 있다).
   그런 부분도 없으면 버린다. 2차 패스에서는 대본 자리(`WAVE_TC_KEEP`)와 겹치는 조각은 버리지 않는다.
4. **시작·끝을 보이는 크기로 좁히기**: 상위 1% − 25dB(토이스토리5에서 약 −28dB)를 넘는 첫·마지막 자리.
   SE 화면은 그보다 작은 소리를 거의 평평하게 그린다. 조각 전체가 그보다 작으면(«S-» 같은 소리) 좁히지 않는다.
5. **프레임으로**: 인점 ceil((시작 − 0.1)×fps), 아웃점 ceil((끝 + 0.25)×fps). Minimum Duration 1초,
   다음 인점 − 간격을 넘으면 자른다. SDH면 장면전환 규칙.

## 6. 대본 넣기 (`fill_script.py`)

1. **대본 줄의 시각**: 참고 자막(영상 안 자막 트랙)에서 같은 문장(유사도 0.8 이상)을 차례로 찾는다.
   한 참고 줄에 대본 줄이 여럿이면 시간을 나눠 준다. 참고 자막이 한 문장을 두 줄로 나눈 경우
   («I now pronounce you husband…» / «and knife.») 뒷줄을 다시 넣지 않는다.
2. 대괄호 소리 표기(`[giggles]`)와 `♪`는 뺀다(TC는 사람 음성만 — 번역·SDH 공통).
3. **자막에 넣기**: 대본 줄 가운데 시각에 가장 가까운 음성 조각(1.5초 안)에 넣는다.
4. **빈 조각 합치기**: 대본이 없는 조각은, 바로 옆(1초 안) 자막의 대본 줄 시각이 그 조각의 음성과
   **실제로 겹칠 때만** 합친다(여유를 두면 웃음·숨소리 조각까지 붙어 인점이 앞으로 갔다).
5. **대본 없는 조각은 지운다**(번역·SDH 공통). 지운 시각을 출력한다.
6. **나누기**: 한 자막이 최대 글자를 넘거나 7초를 넘으면 대본 줄 경계에서 나눈다.
   나누는 자리는 그 안의 쉼(0.08초 이상) 가운데 경계와 가장 가까운 곳, 쉼이 없으면 경계 ±0.5초 안의 가장 작은 소리.
   나눈 조각의 인점·아웃점은 같은 규칙으로 다시 잡는다.
7. **2차 패스**: 자리를 못 찾은 대본 줄(`clip_음성만.srt.unplaced.json`)이 있으면, 그 참고 자막 시각 ±0.3초를
   VAD가 지우지 않게 되살리고(`vad_mask.py ... KEEP.json`), SE 파형을 다시 받아 다시 잡는다.
   외침·배경 아이 목소리·장난감 녹음 목소리는 분리 음성에 소리가 있어도 VAD 확률이 0.01~0.3이었다.
   대본이 근거일 때만 되살리므로 대본 없는 소음은 그대로 걸러진다.

## 7. 사용자가 지적한 오류와 고친 방법 (같은 지적을 되풀이하지 않기)

| 지적 | 원인(측정으로 확인) | 고친 방법 |
|---|---|---|
| 비음성 소리도 들어감 | 보컬 분리만으로는 효과음이 남음 | 5.1 센터 + Silero VAD |
| 인점이 너무 앞 | 시작을 낮은 문턱까지 넓힘(평균 0.047초, 최대 0.127초) | 시작을 넓히지 않음 |
| 자막 나눔이 안 됨 | 끝을 잔향 따라 최대 6.1초 넓혀 다음 말과 붙음 | 끝을 넓히지 않음, 쉼 0.2초 |
| «Star» 앞 덜컥 소리에 인점 | 소음 조각이 대본 줄 시각과 겹쳐 합쳐짐 | VAD 확률 평균으로 거르기, 합치기는 실제 겹칠 때만 |
| «S-»가 잘리고 «-tar»만 | 덜컥+«S-»가 한 조각인데 통째로 버림 | 조각 안 확률 0.5 이상 부분만 남김 |
| 대본 3줄 빠짐 | VAD가 외침·아이·장난감 목소리를 지움 | 2차 패스로 대본 자리 되살림 |
| «and knife.» 두 번 | 참고 자막의 나뉜 뒷줄을 한 번 더 넣음 | 이미 넣은 줄 안의 글자면 넣지 않음 |
| 7초 넘는 자막 | 글자 수는 84자 안 | 7초 넘으면 대본 줄 경계에서 나눔 |
| 인점·아웃점 여유가 너무 많음 | 말 끝 작은 꼬리(−28~−40dB)까지 음성으로 봐 아웃점 약 0.45초 늦음 | 시작·끝을 보이는 크기로 좁힘, 아웃점 끝+0.25초 |

## 8. 넘기기 전 점검과 보고

- 실행 출력의 **버린 조각·지운 대본 없는 자막·못 넣은 대본 줄** 목록을 보고에 적는다.
- 대사 시작 앞 0.6초 안(앞 대사 끝 +0.05초 이후)에 VAD 확률 0.5 이상 + SE 파형 −55dB 넘는 소리가
  이어지면 «앞소리 놓침» 후보로 보고한다.
- 7초 넘는 자막·겹침이 0개인지 센다.
- 소리는 직접 못 들으므로 «확인 못 함: 귀로 듣기»를 적는다. VAD 평균 기준의 여유가 작다
  (토이스토리5: 소음 0.38·0.40 / 대사 최저 0.55) — 새 작품에서는 버린 조각을 들어 확인하게 한다.

## 9. SubtitleEdit 환경 (이 PC, 2026-11-12)

- **SE 4.0.16 포터블**: `%LOCALAPPDATA%\Programs\Subtitle Edit 4\`(설정 `Settings.xml`이 같은 폴더).
  5.3.0(`C:\Program Files\Subtitle Edit`)은 사용자가 별로라고 해서 4.x를 쓴다.
- 재생기 mpv(`libmpv-2.dll`을 SE5 데이터 폴더에서 복사), 배치 `LayoutNumber` 1(화면의 2번),
  메뉴 한국어(`ko-KR`), **영상을 열면 파형 자동 생성**(`WaveformAutoGenWhenOpeningVideo` True).
- 단축키: 강의 문서(구글 문서 «단축키» 탭) 28개를 `tools/se4_shortcuts.py`로 넣었다
  (F1 누르면 인점·떼면 아웃점, F2 다음 자막, F3 아웃점, F4 아래 새 줄, F5 다음 찾기,
  F7 다음으로 확장, F8/Ctrl+F8 오류, C 파형 위치에서 나눔, Esc 재생/정지, PageUp/Down 이동,
  Alt+A 모든 인점 보정, Alt+Space 독백 병합, Alt+Shift+Space 대화 병합, Ctrl+Space 분리 등).
  SE를 다시 설치하면 `py tools/se4_shortcuts.py "<SE4 폴더>/Settings.xml"`.
- SE를 닫고 다시 열 때는 `CloseMainWindow`로 정상 종료한다(강제 종료하면 설정이 안 남는다).
